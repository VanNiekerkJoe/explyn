# Explyn: Code Comprehension

Let’s create a “explain my code app” where a person can upload their entire folder , the system scans through it then will explain what each of their applications do in deep detail ensuring understanding, I want it to have 3 levels beginner , intermediate and advanced knowledge and the ways the code will be explained . I want it to breakdown the data structure, each class , what views do , what the imports are , everything, I want the ui/ux to look like this website : https://toblo.co.za , I wanna use every and any coding language, called Explyn
