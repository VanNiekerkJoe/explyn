

# Explyn — Code Explanation App

## Design
- **Dark theme** inspired by toblo.co.za: dark background (#0a0a0a), white text, subtle borders, rounded cards, clean sans-serif typography, pill-shaped badges/tags
- **Minimal, professional layout** with generous whitespace

## Pages & Flow

### 1. Landing Page
- Hero section with "Explyn" branding and tagline ("Understand any codebase, deeply.")
- Scrolling marquee of supported languages (Python, Java, C++, JavaScript, TypeScript, Go, Rust, C#, Swift, Kotlin, Ruby, PHP, etc.)
- Three feature cards for the explanation levels (Beginner / Intermediate / Advanced)
- CTA button → "Upload Your Code"

### 2. Upload Page
- **Drag & drop folder** upload zone (reads files client-side via File System Access API)
- **Paste code** tab — text area for manual code paste with language selector
- Language auto-detection from file extensions
- File tree preview showing uploaded files before analysis
- Select explanation level: Beginner / Intermediate / Advanced
- "Analyze" button to start

### 3. Analysis Report Page
A structured, full report generated by AI covering:

- **Project Overview** — what the project does, tech stack detected
- **File-by-file breakdown:**
  - Purpose of the file
  - Imports explained (what each import does and why it's needed)
  - Data structures (classes, interfaces, structs, enums, types)
  - Functions/methods — what each does, parameters, return values
  - Views/UI components — what they render and how
  - Design patterns detected
- **Architecture diagram** (text-based) showing how files relate
- Explanation depth adapts to selected level:
  - **Beginner**: Simple analogies, no jargon, "what does this do in plain English"
  - **Intermediate**: Technical but accessible, covers patterns and best practices
  - **Advanced**: Deep internals, performance implications, edge cases

Report rendered with markdown, collapsible sections per file, syntax-highlighted code snippets.

### 4. Follow-up Chat
- Chat panel (slide-out or below report) to ask questions about the analyzed code
- Context-aware — AI remembers the uploaded codebase
- Streams responses token-by-token

## Backend
- **Lovable Cloud** with Supabase edge function calling **Lovable AI** (Gemini model)
- Edge function receives file contents + level, returns structured analysis
- Separate chat edge function for follow-up Q&A with conversation history

## Key Technical Details
- Client-side folder reading (no server upload needed for files)
- File size/count limits displayed to user
- Loading states with progress indicators during analysis
- Report sections are collapsible for easy navigation
